#  Travel Diary

## 도메인 정리

- 회원이 전세계의 도시를 여행하며 본인이 방문한 도시, 장소, 그리고 그곳에서의 본인의 후기를 작성한다. 이를 Travel Diary라고 한다.
- 회원은 본인의 여정을 여러 개 등록할 수 있다.
- 하나의 여정은 여러 개의 도시 방문 이력을 저장할 수 있다. 출발지는 반드시 존재해야 하며 경유지도 1개 이상이어야 한다.
- 하나의 도시는 여러 장소 방문 이력을 저장할 수 있다.
- 도시와 장소 방문에 대한 후기를 저장할 수 있다.


## 도메인 모델

### 회원 : Member
_Entity_

### 여정 : Journey
_Entity_

#### 속성
- `id`
- `memberId`
- `startDate` : 여행 시작일
- `endDate` : 여행 종료일
- `name` : 여정 이름
- `createdAt`
- `lastModifiedAt`
- `isActive`
- `visibility`

#### 행위
- 회원은 여정을 등록할 수 있다.
- 여정은 등록한 회원(memberId)에 의해서만 수정되거나 조회될 수 있다.
- 여정은 이름, 여행 시작일, 여행 종료일 3가지를 수정할 수 있다.
- 여정은 최초 생성 시 활성 상태가 되며, 여정을 등록한 사용자에 의해 비활성화 될 수 있다.
- 회원은 여정의 공개 범위를 수정할 수 있다.

### 도시 : City
_Entity_

#### 속성
- `id`
- `name` : 도시명
- `description` : 도시 설명
- `imageId` : 배경사진 ID
- `latitude` : 위도
- `longitude` : 경도

#### 행위
- 회원은 `name`으로 도시를 검색할 수 있다.
- 등록되지 않은 도시를 조회하는 경우, 생성형 AI를 통해 자동으로 엔티티를 생성하여 저장한 후 이를 조회 결과로 노출한다. (비동기적 신규 생성)

### 도시방문 : CityVisit
_Entity_

#### 속성
- `id`
- `city`
- `journey`
- `reflection`
- `visitDate` : 방문 날짜

#### 행위
- 회원은 여정을 생성한 후, 도시 방문 이력을 저장할 수 있다.
- 회원은 여정을 통해서 도시 방문 이력을 조회할 수 있다.
- 회원은 여정을 통해서 도시 방문 이력을 수정할 수 있다.

- `latitude` : 위도
